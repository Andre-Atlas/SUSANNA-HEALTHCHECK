# 03 - Análise Exploratória dos Dados (EDA)

Este diretório contém os estudos, notebooks estatísticos e análises exploratórias conduzidas sobre o corpus de saúde pública do Distrito Federal.

## 📊 Itens Incluídos
- `notebooks/`: Jupyter Notebooks com análises de distribuição de textos, tamanho de sentenças e correlações.
- `reports/`: Gráficos gerados, projeções TF-IDF, similaridade de cosseno entre documentos e métricas de cobertura.
- `cartilha/`: Análise estrutural da Carta de Serviços ao Cidadão do SUS.
