# Changelog

## 0.2.0 — preparação para corpus e RAG real

- extração de acesso a dados para repositories;
- separação de serviços de aplicação;
- proveniência de fonte para estabelecimentos;
- proteção contra exclusão de fontes com dependências;
- migration de hardening;
- recuperação híbrida estruturada + RAG;
- classificação com normalização e contexto conversacional;
- contexto territorial explícito extraído da pergunta;
- limpeza de sessão para suportar "Nova conversa" no frontend;
- validação de dimensão de embeddings no provider e ingestão;
- ingestão mais segura, preservando índice anterior até os embeddings novos estarem prontos;
- testes básicos ampliados;
- script de verificação do Ollama;
- documentação de arquitetura, API e próximas fases.
