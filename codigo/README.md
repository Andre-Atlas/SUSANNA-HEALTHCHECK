# 08 - Código-Fonte da Aplicação

Área reservada para o versionamento do código-fonte da solução SUSANA.

## 📦 Módulos Previstos
- `backend/`: API FastAPI com pipeline RAG híbrido, NLU, guardrails e indexadores.
- `frontend/`: Interface moderna e acessível em Next.js (TypeScript + Tailwind/Vanilla CSS).
- `scripts/`: Scripts de avaliação automatizada, benchmark e ingestão do corpus.

*Nota: O código será versionado progressivamente a partir da branch de homologação testada e validada.*
