# 01 - Datasets & Corpus Oficial

Este diretório é reservado para o versionamento dos dados, metadados e catálogo de fontes oficiais utilizadas no projeto SUSANA.

## 📁 Subestruturas Sugeridas
- `raw/`: Dados tabulares brutos coletados da SES-DF, InfoSaúde e Ministério da Saúde.
- `processed/`: Dados tratados, higienizados e unificados para indexação.
- `corpus/`: Arquivos estruturados (JSON/Markdown) para a base de conhecimento vetorial e híbrida.
- `catalogo_do_corpus.md`: Mapeamento de fontes oficiais, URLs e periodicidade de atualização.
