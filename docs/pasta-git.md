# Pasta `.git/`

É o diretório interno que o Git usa para guardar o histórico de commits, referências de branches, configurações e o estado de arquivos versionados.

Não é conteúdo normal do projeto nem deve ser editado manualmente. Apagá-la remove o histórico e a ligação deste diretório de trabalho com o repositório Git; use comandos Git para administrar branches, commits e referências.
