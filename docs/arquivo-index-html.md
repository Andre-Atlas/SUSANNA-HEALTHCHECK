# `index.html`

Define a estrutura da página carregada pelo navegador: navegação, conteúdo institucional, área de conversa, campo de pergunta, botões e regiões usadas para anunciar estado à tecnologia assistiva.

O servidor local entrega este arquivo quando o navegador abre `/` ou `/index.html`. Ele carrega `styles.css` para aparência e `app.js` para interação. O HTML não busca páginas gov.br nem chama o Ollama diretamente.
