# Pasta `evaluation/`

Guarda casos de avaliação e relatórios produzidos pelos scripts do projeto. Os arquivos podem registrar resultados de perguntas de teste, busca, revisão documental, aceitação e desempenho.

Os scripts podem criar relatórios novos nessa pasta. Os JSON são artefatos de avaliação, não conteúdo consultado pelo chat durante uma conversa. Alguns relatórios podem refletir versões antigas do código; confira a data e a versão avaliada antes de usar um resultado como evidência do comportamento atual.

O CSV `analytics-summary.csv` é um resumo local. Ele é ignorado pelo Git; os demais relatórios podem estar versionados conforme a finalidade de cada avaliação.
