# `evaluate_search.py`

Compara estratégias de busca lexical local — busca original, expansão de termos e seleção de resultados — usando casos em `evaluation/` e documentos de `sources/`.

Não chama o Ollama para responder. Produz métricas e resultados para analisar a qualidade da recuperação; é uma ferramenta de desenvolvimento executada separadamente do servidor.
