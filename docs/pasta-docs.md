# Pasta `docs/`

Reúne a documentação do SUSANNA-HEALTHCHECK: explicações da arquitetura, instruções de uso, decisões, avaliações e registros de etapas do projeto.

Os arquivos Markdown são escritos e revisados pela equipe. Eles não são carregados pelo servidor para gerar respostas e não são uma base de conhecimento consultada pelo chatbot.

O índice [Pastas do projeto](pastas-do-projeto.md) ajuda a navegar pelas explicações de cada diretório.
