# Pasta `piloto/`

Contém materiais do piloto do projeto, como orientações aos participantes, registros de aceite, feedback, problemas encontrados e verificações prévias.

É uma pasta de documentação e acompanhamento. O servidor do chatbot não carrega esses arquivos para responder perguntas. Revise o conteúdo antes de compartilhar, pois registros de piloto podem refletir uma etapa específica do projeto.
