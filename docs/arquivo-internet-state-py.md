# `internet_state.py`

Escolhe e cria um diretório privado específico do usuário para guardar estado da demonstração externa, como configuração do ngrok, credenciais temporárias, trava de sessão e logs.

É usado por `internet_demo.py` e `configurar_ngrok.py`. Esses dados ficam fora do repositório para evitar versionar segredos.
