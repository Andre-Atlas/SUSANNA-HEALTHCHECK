# Pasta `backups/`

Guarda cópias locais de segurança, que podem incluir arquivos de banco de dados e um bundle Git criado para preservar um estado anterior do repositório.

Os backups não são consultados pelo chatbot e não substituem os arquivos ativos. A pasta é ignorada pelo Git para evitar publicar cópias grandes ou acidentais. Antes de apagar ou restaurar qualquer item, confira a data, o conteúdo e se a cópia ainda é necessária.
