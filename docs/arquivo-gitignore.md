# `.gitignore`

Lista caminhos e padrões que o Git deve ignorar, como caches Python, ambientes virtuais, arquivos locais de configuração, bancos de dados e backups em certos diretórios, `.internet/`, `.mlflow/` e um CSV gerado.

Isso evita que artefatos locais sejam adicionados por engano. Não apaga arquivos já existentes e não garante, por si só, que um arquivo já versionado deixe de ser acompanhado pelo Git.
