# Pasta `tests/__pycache__/`

É o cache de bytecode Python correspondente a módulos importados dentro de `tests/`. O interpretador cria arquivos `.pyc` ali para evitar recompilar os módulos a cada execução.

Não contém casos de teste nem resultados. Pode ser recriada automaticamente e é ignorada pelo Git, assim como a pasta `__pycache__/` da raiz.
