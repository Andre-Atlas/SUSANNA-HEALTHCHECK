# Pasta `.venv/`

É o ambiente virtual Python criado para este projeto. Contém uma instalação isolada do interpretador (ou referências a ele) e os pacotes instalados para evitar misturá-los com outros projetos.

Não contém o código-fonte principal nem os dados usados para responder. É específica do computador e da instalação; por isso, não deve ser compartilhada nem versionada. Pode ser recriada com Python e os arquivos de dependências do projeto. Apagá-la remove os pacotes instalados nesse ambiente.
