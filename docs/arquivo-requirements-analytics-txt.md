# `requirements-analytics.txt`

Lista dependências opcionais das ferramentas de análise: pandas para sumarizar relatórios e MLflow para acompanhar métricas entre execuções.

Instalar essas dependências não é necessário para iniciar o servidor local ou conversar com o chatbot. São usadas por `analyze_evaluations.py` e pelos modos de benchmark que registram no MLflow.
