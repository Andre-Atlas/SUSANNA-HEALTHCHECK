# Projeto SUSANA — Assistente Virtual Oficial da SES-DF

Repositório estruturado para versionamento, governança, dados e documentação do projeto **SUSANA** (Sistema Único de Saúde com Atendimento e Navegação Aumentada).

---

## 🗂️ Estrutura Arquitetural do Repositório

```text
.
├── datasets/                  # Catálogo e dados brutos/tratados da SES-DF e SUS
├── requisitos/                # Requisitos Funcionais (RF) e Não Funcionais (RNF)
├── eda/                       # Análises Exploratórias de Dados (Cartilha, Vacinas, SUS Digital)
├── guiding-questions/         # Perguntas norteadoras e hipóteses de negócio/saúde
├── scrum-organizacao/         # Metodologia ágil, papéis e cerimônias da equipe
├── modelo-ia-relatorio/       # Documentação do modelo (RAG, Embeddings, Guardrails)
├── produto/                   # Visão final do produto, personas e escopo
└── codigo/                    # Código-fonte da aplicação (Backend RAG + Frontend UI)
```
