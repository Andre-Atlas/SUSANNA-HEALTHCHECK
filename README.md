# Projeto SUSANA — Assistente Virtual Oficial da SES-DF

Repositório estruturado para versionamento, governança, dados e documentação do projeto **SUSANA** (Sistema Único de Saúde com Atendimento e Navegação Aumentada).

---

## 🗂️ Estrutura Arquitetural do Repositório

```text
.
├── 01-datasets/               # Catálogo e dados brutos/tratados da SES-DF e SUS
├── 02-requisitos/             # Requisitos Funcionais (RF) e Não Funcionais (RNF)
├── 03-eda/                    # Análise Exploratória de Dados (Notebooks e relatórios)
├── 04-guiding-questions/      # Perguntas norteadoras e hipóteses de negócio/saúde
├── 05-scrum-organizacao/      # Metodologia ágil, papéis e cerimônias da equipe
├── 06-modelo-ia-relatorio/    # Documentação do modelo (RAG, Embeddings, Guardrails)
├── 07-produto/                # Visão final do produto, personas e escopo
└── 08-codigo/                 # Código-fonte da aplicação (Backend RAG + Frontend UI)
```
